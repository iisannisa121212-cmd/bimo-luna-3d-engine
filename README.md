# Blocky Kids 3D Engine — Prototype 0.1

Ini adalah prototipe awal mesin animasi 3D Bimo & Luna.

## Isi
- `index.html`: aplikasi demo 3D berbasis Three.js.
- Karakter blocky orisinal Bimo dan Luna.
- Adegan pendek: dikejar zombie, masuk rumah, memasang jebakan, dan plot twist.
- Dialog tampil sebagai teks di layar (belum suara).
- Tombol rekam menghasilkan file WebM, bukan MP4.

## Cara mencoba
Aplikasi memuat Three.js dari CDN, jadi perlu internet.
Karena menggunakan JavaScript module, buka melalui server web (misalnya GitHub Pages), bukan dengan membuka file HTML langsung dari penyimpanan HP.

## Batasan prototipe
Ini belum menjadi generator otomatis dari prompt/Claude Skill. Belum ada:
- sinkronisasi suara/dialog,
- editor skenario,
- penyimpanan aset karakter terpisah,
- ekspor MP4,
- sistem produksi banyak episode.

Tahap berikutnya adalah menguji demo ini di browser, lalu mengembangkan dialog bersuara, sistem adegan, dan integrasi skill.
